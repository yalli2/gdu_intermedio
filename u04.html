접속법 현재 형태

핵심 문법핵심 어휘예문연습 문제 (4세트)
학습 목표
  • 규칙·불규칙 접속법 현재를 만든다
  • 어간 변화와 철자 변화를 정확히 적용한다
  • 독립문에서의 접속법(ojalá, quizá)을 쓴다

핵심 문법

형태 규칙

직설법 현재 yo형에서 -o를 빼고 반대 모음 어미: hablar → habl-e, comer → com-a, tener(tengo) → teng-a, conocer(conozco) → conozc-a.

유형예
철자 변화buscar → busque, llegar → llegue, empezar → empiece, coger → coja
e→ie / o→uepensar → piense (pensemos), volver → vuelva (volvamos)
-ir 어간 변화sentir → sienta, sintamos / dormir → duerma, durmamos / pedir → pida, pidamos
완전 불규칙ser → sea, ir → vaya, estar → esté, saber → sepa, haber → haya, dar → dé

독립문 속 접속법

Ojalá + 접속법: 바람(Ojalá apruebes). Quizá(s)/Tal vez + 접속법(불확실)·직설법(가능성 높음). ¡Que + 접속법!: 기원(¡Que te vaya bien! ¡Que descanses!).

발음 주의
dé(dar 접속법)와 de(전치사), esté(estar 접속법)와 este(지시사)는 강세 부호로 구별됩니다.
